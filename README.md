## About this project

OpenCode Toolkit is a community-oriented reference for documenting useful commands, workflows, and productivity practices for AI-assisted development.

The goal is to make command usage easier to understand, explain its limitations, and encourage more reliable development workflows.

## What you'll find

- **Command reference:** Understand what each command is intended to do.
- **Context management:** Learn how to handle long-running sessions.
- **Model selection:** Choose models according to task complexity.
- **Session continuity:** Organize work across multiple sessions.
- **Best practices:** Protect your work and avoid relying on undocumented behavior.

## Important note

Commands and their behavior may vary depending on the OpenCode version, installed extensions, configuration, or external tools. Verify that each command is supported in your environment before using it.

This repository is an independent documentation project and is not an official OpenCode project unless explicitly stated otherwise.
